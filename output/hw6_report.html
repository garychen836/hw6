1. Caching: the handbook is paid for on every call

The shop handbook is 10,058 tokens and goes first in the prompt, so OpenAI can cache it. We ran all 12 practice documents with and without caching (after one warm-up call). Every model request was logged.

86.0% cheaper with caching: $0.026625 without versus $0.003715 with, for 12 documents ($0.002219 versus $0.000310 per document).

Which layer does what (documents correct out of 12)

  • Code (a sanitizer that keeps only what a person would see) fixed every override by itself.
  • Design (a reading model with no tools; the decision and reason are computed in Python from the handbook) guarantees nothing in a document can trigger a payment or email or put a link in the answer, but on its own it still believed hidden price notes.
  • Prompt (rules that document text is data) helps, but is the weakest alone: the model still sees the hidden text.

Hardening for attack A. The original sanitizer checked colour, size and page position, so it did not see text that was dark, large and in the page but covered by a shape. Without a covered-text check, the code layer alone returned the hidden $18.90 in 3/3 runs; with the check it returned the visible $24.90 in 3/3. The full stack had already held because the prompt and the model preferred the main table, but a defense should not rely on that. The sanitizer now drops characters painted over by a later filled shape. Attack B needed no change: the sanitizer only reads the inline body and ignores attachments. After hardening, all 12 practice documents were rerun: 12/12 and 12/12.

5. Recommendation

Turn it on for real vendor mail, but as a draft assistant: the agent reads each quote and proposes recommend or do not recommend with a one-line reason, and a buyer confirms. The payment and email tools stay behind a typed human sign-off and are never reachable from reading a document. At 1,000 documents a day the defended agent with caching costs about $5.64 a month; without caching the same defended agent would cost about $33.34, and the undefended agent $8.96 with caching or $66.56 without. Defense is therefore not a cost argument: it is cheaper than leaving the model in charge.

Risks and next steps. The model is not deterministic and our attack tests are small, so a clean score is evidence, not proof; keep a human in the loop and review the trap log and the sanitizer flags weekly. Attachments are deliberately not read, so a quote that arrives only as an attachment needs a person. Keep red-teaming with new tricks (the covered-text attack was a real gap), and re-run the 12-document check whenever the handbook, prompt or model changes.
